# Kirmya Privacy Controls & Profile Visibility Settings

## 1. User Privacy Tiers
- **Profile Visibility**: `Public` (all visitors), `Connections` (1st-degree network only), `Private` (hidden from non-authenticated requests).
- **Recruiter Discoverability**: Toggle to allow or disallow recruiter proactive candidate search and AI matching index inclusion.
- **Messaging Privacy**: Restrict direct messaging to accepted connections or open communication.
