# Kirmya Accessibility (a11y) & WCAG 2.1 AA Verification

## 1. Accessibility Standards & Automated Checks
- **Keyboard Navigation**: All interactive elements (buttons, modals, tabs, dropdowns) support Tab, Shift+Tab, Enter, Space, and Escape keyboard traps.
- **Color Contrast**: 4.5:1 minimum contrast ratio across light and dark mode MUI v6 theme tokens.
- **Screen Reader Semantics**: Proper ARIA landmarks, `aria-expanded`, `aria-label`, and `aria-live="polite"` on dynamic notification badges and toasts.
