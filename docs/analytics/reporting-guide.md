# Kirmya Custom Report Generation & Scheduled Delivery Guide

## 1. Custom Analytical Reports & Automated Schedules
- **Custom Report Builder**: Build scoped queries filtering by date ranges, entity modules, and target metric aggregations.
- **Scheduled Cron Jobs**: Configure automated executive delivery (Daily, Weekly, Monthly) via background worker schedules.
- **Audit Logging**: Every report generation and scheduled dispatch is recorded in append-only administrative audit tables.
