# Kirmya Personal Career Analytics User Guide

## 1. Candidate Career Growth Dashboard (`/analytics`)
- **Application Performance**: Track application submission rates, recruiter review timestamps, and interview invitation conversions.
- **Skill Progression & Milestones**: Monitor verified skill badges, completed course modules, and career roadmap progress.
- **Privacy Controls**: Adjust analytics consent settings under `/settings/privacy` to control telemetry and personalized recommendations.
