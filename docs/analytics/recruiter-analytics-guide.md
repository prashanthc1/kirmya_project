# Kirmya Recruiter Performance & Pipeline Analytics Guide

## 1. Recruiter Sourcing & Pipeline Insights
- **Requisition Funnels**: Track impressions, click-to-apply ratios, candidate shortlists, and interview completion rates per job posting.
- **Outreach & Response Metrics**: Measure candidate response latency and connection acceptances across active sourcing campaigns.
- **Tenant Data Isolation**: Recruiters only access analytics for jobs and hiring teams to which they are explicitly assigned.
