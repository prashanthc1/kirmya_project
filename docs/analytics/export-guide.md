# Kirmya Analytics Export & Data Integrity Manual

## 1. Secure CSV & Data Export Operations
- **Supported Formats**: Export aggregate metrics and time-series summaries to CSV formats with strict field sanitization.
- **Export Rate Limiting**: User-level and role-level throttling prevents export abuse and server load exhaustion.
- **PII Scrubbing**: Individual personal identifiers are automatically stripped from analytics export archives.
