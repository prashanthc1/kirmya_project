# Kirmya Analytics Event Taxonomy & Standardized Domain Events

## 1. Domain Event Taxonomy
- `user.registered`: Fired upon successful account creation.
- `user.verified`: Fired when email verification token is validated.
- `profile.completed`: Fired when required career profile sections reach 100%.
- `job.published`: Fired when a recruiter publishes a new vacancy.
- `application.submitted`: Fired when a candidate submits an application.
- `interview.scheduled`: Fired when an interview invitation is confirmed.
- `learning.completed`: Fired when a course module or assessment is completed.
