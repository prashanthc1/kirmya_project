# Kirmya Job Search Ranking & Relevance Scoring Manual

## 1. Relevance Scoring Factors
| Ranking Signal | Weight | Description |
| :--- | :---: | :--- |
| **Exact Title Match** | 35% | High relevance match on job position title |
| **Skill Overlap** | 25% | Match against candidate's verified skills |
| **Recency / Freshness** | 20% | Gaussian decay boost for jobs posted within 14 days |
| **Location / Remote** | 15% | Proximity match or remote preference alignment |
| **Listing Completeness** | 5% | Detailed role description, requirements, and salary bounds |
