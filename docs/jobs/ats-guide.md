# Kirmya Applicant Tracking System (ATS) Guide

## 1. Visual Kanban Pipeline Architecture
- **Interactive Drag-and-Drop & Accessible Dropdown**: Move candidates between stages (`Applied`, `Screening`, `Shortlisted`, `Interview`, `Offer`, `Hired`, `Rejected`).
- **Scorecards & Assessment Rubrics**: Structured rating categories (Technical Skills, Cultural Alignment, Communication) with average score computation.
- **Internal Note Confidentiality**: Internal recruiter comments strictly shielded from candidate responses.
