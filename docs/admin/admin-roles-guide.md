# Kirmya Administrative Roles & Authority Hierarchy Manual

## 1. Role Scopes & Responsibilities
- **Super Admin**: Complete governance authority across system settings, user permissions, database operations, and maintenance modes.
- **Platform Admin**: Configuration of global feature flags, marketplace categories, and standard operational parameters.
- **Trust & Safety Admin**: Enforcement desks, scam job investigations, user restriction reviews, and appeal determinations.
- **Operations Admin**: Infrastructure telemetry, background worker queues, cache maintenance, and incident triage.
