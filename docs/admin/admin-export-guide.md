# Kirmya Administrative Report Exports & Auditing Manual

## 1. Controlled Data Exports & Dual Authorization
- **High-Risk Export Approvals**: Bulk exports containing user records or financial metrics require secondary administrator sign-off.
- **Export Throttling**: Strict daily rate limits prevent unauthorized bulk data extraction.
- **Audit Footprint**: Every export event records the requesting administrator, specific filters applied, row counts exported, and timestamp.
