# Kirmya Community Reporting & Safety Feedback Manual

## 1. Multi-Channel Reporting Pipeline
- **Standardized Categories**: Users report suspicious jobs, abusive messages, fake profiles, and scam campaigns across uniform policy keys.
- **Evidence Minimization**: Reports capture only the minimal necessary context to investigate violations without exposing broader private user histories.
- **User Feedback**: Reporters receive status updates when their report is reviewed and resolved.
