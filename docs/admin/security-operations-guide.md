# Kirmya Security Operations, Threat Monitoring & Incident Response Manual

## 1. Security Event Monitoring & Threat Defenses
- **Security Incident Log**: Aggregates credential stuffing indicators, anomalous IP logins, and privilege escalation attempts in real-time.
- **Account Takeover Mitigation**: Step-up re-authentication, active session revocation, and temporary lockdown controls protect compromised profiles.
- **Rate-Limit Administration**: Inspect and manage IP/User token-bucket throttles across sensitive authentication and search endpoints.
