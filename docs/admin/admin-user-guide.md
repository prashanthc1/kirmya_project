# Kirmya Administrative Console & Governance User Guide

## 1. Navigating Admin Dashboard Features
- **Executive Overview (`/admin`)**: Monitor platform health, open moderation queues, urgent safety alerts, and account appeal backlogs.
- **User & Org Triage**: Search users and organizations by unique identifier or verified email to inspect safety histories and apply temporary restrictions.
- **Moderator Assignment**: Claim and resolve moderation cases with standardized policy violation tags and explicit reason logging.
