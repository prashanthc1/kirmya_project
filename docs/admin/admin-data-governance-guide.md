# Kirmya Administrative Data Governance & Compliance Manual

## 1. Compliance Workflows & Data Subject Rights (DSR)
- **DSR Administration**: Review and process user data export requests and account erasure requests within statutory GDPR/CCPA deadlines.
- **Legal Hold Management**: Apply granular legal holds on specific user profiles or organization records to prevent deletion during active compliance inquiries.
- **Cascading Anonymization**: Account deletions trigger automated sanitization of personal references while preserving referential integrity in reporting aggregates.
