# Kirmya Skill Gap Analysis & Career Growth Recommendations

## 1. Skill Gap Detection Algorithm
When candidate profile skills are evaluated against target aspirational roles:
```
Gap Score = 1 - (Matching Skills Count / Target Role Required Skills Count)
```

---

## 2. Integrated Free Learning Pathways
Detected skill gaps automatically link to relevant free open-access learning resources and community study groups within Kirmya to empower career recovery.
