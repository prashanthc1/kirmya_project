# Kirmya Real-Time Messaging & Direct Conversations User Guide

## 1. Professional Messaging Navigation
- **Free Direct Communication**: All 1-to-1 direct messaging, conversation searching, and file attachment sharing are 100% free with zero paywalls.
- **Messages Inbox (`/messages`)**: Search past conversation history, view online presence badges, and track read receipts.
- **Privacy & Blocking**: Block abusive contacts with immediate conversation shielding and reporting capabilities.
