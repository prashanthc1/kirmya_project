# Kirmya Grafana & Operational Monitoring Dashboards

## 1. Standard Operational Dashboard Suite
- **Platform Executive Health**: Global availability, request volume (RPS), active users, error budgets.
- **API Performance Studio**: Endpoint-level P50/P95/P99 latencies, status code distribution (2xx/4xx/5xx).
- **PostgreSQL Database Desk**: Connection pool utilization, query latency distribution, slow queries.
- **Background Worker & NATS Queue Hub**: Queue backlog, throughput, DLQ retry rate.
