# Kirmya Recruiter Dashboard & Candidate Management User Guide

## 1. Navigating the Recruiter Workspace
- **Executive Recruiter Hub (`/recruiter/dashboard`)**: Monitor open job vacancies, active applicants, shortlisted candidates, and upcoming interviews.
- **Candidate Management**: Triage applications, attach private evaluation notes, assign candidates to teammates, and coordinate interview slots.
- **Direct Candidate Messaging**: Reach out directly to applicants within the approved application context.
