# Kirmya Candidate Discovery & Search Manual for Recruiters

## 1. Candidate Discovery & Search Filters
- **Consent-Grounded Discovery**: Candidates appear in recruiter searches only if they have explicitly enabled "Recruiter Visibility" or "Open to Work".
- **Granular Filters**: Filter candidate pools by verified skill proficiencies, experience tiers, target job titles, and location preferences.
- **Anti-Scraping Defenses**: Token-bucket throttling prevents bulk profile harvesting while maintaining responsive search performance.
