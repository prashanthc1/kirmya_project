# Kirmya Candidate Hiring Pipeline & Stage Triage Manual

## 1. Multi-Stage Candidate Pipelines
- **Configurable Stage Lifecycle**: Manage applicants across standardized stages (New, Screening, Shortlisted, Interview, Offer, Hired, Rejected).
- **Transactional Stage Transitions**: Pipeline stage advancements trigger transactional updates and synchronization with candidate application tracking views.
- **Private Evaluation Notes**: Interviewer feedback and recruiter notes are preserved privately within the organization hiring context.
