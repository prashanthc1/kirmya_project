# Kirmya Employer & Organization Onboarding Guide

## 1. Employer Account Setup & Verification
- **Organization Workspace**: Set up enterprise profiles, headquarters locations, verified domain addresses, and employer branding assets.
- **Verification Workflow**: Submit business documentation to platform administrators to obtain the verified employer trust badge.
- **Team Provisioning**: Invite recruitment leads, hiring managers, and interviewers into dedicated organization tenants.
