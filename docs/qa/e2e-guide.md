# Kirmya End-to-End (E2E) Test Automation Guide

## 1. Core End-to-End User Workflows
1. **Candidate Onboarding & Application**:
   - `Register -> Verify Email -> Complete Profile -> Search Jobs -> Apply -> View ATS Timeline`.
2. **Recruiter Hiring Desk**:
   - `Recruiter Login -> Post Job -> Review Candidate Queue -> Move Stage -> Submit Scorecard`.
3. **Community & Networking**:
   - `Search Person -> Send Connect -> Join Community -> Post Discussion -> Direct Message`.
