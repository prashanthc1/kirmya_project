# Kirmya Job Search, Filters & Recommendation Manual

## 1. Job Search & Opportunity Discovery
- **Multi-Parameter Filtering**: Filter active vacancies by technical skills, salary tiers, remote/hybrid status, experience requirements, and company.
- **Saved Searches & Alerts**: Save search queries to receive automated notification alerts when matching vacancies are published.
- **Explainable Match Scoring**: Job recommendations display transparent match rationales based on verified candidate profile skills.
