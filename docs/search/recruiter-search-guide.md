# Kirmya Recruiter Discovery & Talent Sourcing Manual

## 1. Candidate Sourcing & Recruiter Discovery
- **Recruiter Discovery Mode**: Sourcing tools query exclusively candidates who have opted into "Recruiter Visibility" or "Open to Work".
- **Resume Query Controls**: Text search over candidate resume documents is authorized exclusively within assigned organization scopes.
- **Anti-Scraping Defenses**: Token-bucket throttling prevents bulk profile harvesting while maintaining responsive search performance.
