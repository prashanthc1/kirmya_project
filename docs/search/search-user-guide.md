# Kirmya Global Search & Discovery User Guide

## 1. Navigating Universal Search Capabilities
- **Global Search Bar**: Search across Jobs, Professionals, Companies, Communities, Skills, and Learning Modules from any page.
- **Search Suggestions & History**: Real-time autocomplete suggestions with options to inspect, manage, or clear recent search queries.
- **Faceted Filters & Sorting**: Refine results by location, employment tier, seniority, remote arrangement, and posting date.
