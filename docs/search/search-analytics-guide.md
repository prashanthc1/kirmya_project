# Kirmya Search Analytics, Zero-Result Tracking & Health Metrics Manual

## 1. Search Telemetry & Quality Insights
- **Zero-Result Query Diagnostics**: Tracks queries with zero matches to identify emerging skills or missing marketplace offerings.
- **Latency & Cluster Metrics**: OpenTelemetry integration records query P95 latency, indexing queue depth, and failover switch events.
- **Privacy-Preserving Telemetry**: Search analytics are stored in aggregate without associating personal identities with specific keyword logs.
