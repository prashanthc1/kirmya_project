# Kirmya Unified Global Search Operations Manual

## 1. Multi-Entity Unified Search Execution
- **Federated Query Parsing**: Automatically splits queries into entity categories (People, Jobs, Companies, Groups, Resources) with prioritized preview cards.
- **Typo Tolerance & Stemming**: Built-in Levenshtein distance matching and Porter stemming handle minor spelling variations seamlessly.
- **Synonym Normalization**: Industry dictionaries map interchangeable terms (e.g. "Software Engineer" <-> "Developer", "Go" <-> "Golang").
