# Kirmya Notification Digest & Quiet Hours Scheduling Manual

## 1. Batching, Digest Aggregation & Quiet Hours
- **Digest Schedules**: Low-priority updates (weekly job summaries, network connection activity) are compiled into Daily or Weekly digest emails.
- **Quiet Hours Enforcement**: User-configured Do-Not-Disturb windows suppress non-critical push/in-app notifications until the quiet window concludes.
- **Critical Event Bypass**: High-severity security notices (password resets, account compromises) bypass quiet hours unconditionally.
