# Kirmya Notification Center & Preferences User Guide

## 1. Notification Hub Navigation
- **Navbar Bell Badge**: Real-time unread badge alerting you to new application updates, interview requests, and recruiter messages.
- **In-App Notification Center (`/notifications`)**: Filter notifications by category (`Jobs`, `Applications`, `Interviews`, `Networking`, `Messages`, `Security`).
- **One-Click Read Management**: Mark individual alerts or entire categories as read with instant state synchronization.
