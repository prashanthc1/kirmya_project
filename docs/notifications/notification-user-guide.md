# Kirmya Notification Center & Preferences User Guide

## 1. Managing Your Notifications
- **Navbar Bell Badge**: Displays real-time unread notification count with instant popover preview of recent updates.
- **Notification Hub (`/notifications`)**: Filter by category (`All`, `Unread`, `Jobs`, `Applications`, `Network`, `Messages`, `Interviews`, `Career`).
- **Preferences Matrix**: Toggle delivery channels (In-App, Email) per event category.
- **Do Not Disturb (Quiet Hours)**: Configure local time windows to silence non-critical notifications.
