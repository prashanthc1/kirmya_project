# Kirmya Privacy-by-Design Principles & Technical Controls

## 1. Core Privacy-by-Design Tenets
- **Data Minimization**: Collect only fields strictly necessary for career discovery and professional networking.
- **Privacy-Preserving Defaults**: All new profiles default to connection-only visibility until explicitly made public by the user.
- **Aggregation Thresholding**: Analytics metrics enforce minimum group size ($k \ge 5$) to prevent re-identification.
