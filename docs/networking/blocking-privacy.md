# Kirmya Relationship Privacy, Blocking & Spam Prevention

## 1. Zero-Leakage Blocking Invariants
- **Bidirectional Invisibility**: When User A blocks User B, both users become invisible to each other in search, connection lists, and group member directories.
- **Immediate Disconnect**: Existing connections and active conversation subscriptions are instantly severed.
- **Spam Throttling**: Connection requests limited to 30/day; messages to non-connections rate-limited to prevent mass unsolicited outreach.
