# Kirmya Career Profile & Portfolio User Guide

## 1. Navigating Career Profile Features
- **Profile Completeness Indicator**: Track completion score and receive prioritized suggestions to improve profile visibility.
- **Section Management**: Reorder and update work experience, degrees, verified skills, industry certifications, and portfolio projects.
- **Privacy Toggles**: Switch between public discoverability, recruiter-only mode, connections-only visibility, or complete privacy.
