# Kirmya Profile Privacy, Recruiter Visibility & Field Shielding

## 1. Granular Field-Level Privacy Matrix
- **Visibility Levels**: Toggle public visibility, recruiter-only mode, connections-only mode, or completely private status.
- **Selective Field Shielding**: Hide email, phone number, salary expectations, or current employer from discovery indexes.
- **Mutual Block Enforcement**: Blocked users are immediately stripped of profile access across search, networking, and messaging.
