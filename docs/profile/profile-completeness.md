# Kirmya Profile Completeness Scoring Engine

## 1. Weight Breakdown (Total: 100%)

| Profile Section | Weight | Completion Criteria |
| :--- | :--- | :--- |
| **Basic Info & Photo** | 20% | Avatar uploaded + Headline + Location populated |
| **About / Summary** | 15% | About section contains >= 50 characters |
| **Work Experience** | 25% | At least 1 verified work experience entry |
| **Education** | 15% | At least 1 education entry |
| **Skills** | 15% | At least 3 structured skills selected |
| **Resume Upload** | 10% | At least 1 active primary resume uploaded |

---

## 2. Completeness Recommendations
The profile dashboard displays actionable prompts (e.g. *"Add 2 more skills to reach 85% completeness"*) to guide candidates toward higher recruiter visibility.
