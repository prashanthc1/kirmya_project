# Kirmya Resume Versioning & Application Snapshot Manual

## 1. Multi-Target Resume Versions
- **Role-Specific Variants**: Candidates can maintain distinct resume variants tailored for specific target domains (Engineering, Management, Operations).
- **Application Snapshot Integrity**: When applying to a job, the submitted resume state is snapshotted to preserve historical application accuracy regardless of subsequent profile edits.
- **Default Designation**: Users designate a primary default resume for one-click application workflows.
