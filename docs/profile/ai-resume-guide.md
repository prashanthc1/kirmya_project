# Kirmya AI-Assisted Resume Optimization & Profile Guidance Manual

## 1. Ethical AI Career Coaching Boundaries
- **Assistive Suggestions**: AI tools offer headline refinements, bullet point action-verb enhancements, and skill-gap recommendations.
- **Anti-Fabrication Guardrails**: The system strictly refuses to invent credentials, falsify work histories, or generate unverifiable achievements.
- **User Review Mandate**: All AI suggestions require candidate explicit review and approval before being saved to profile or resume records.
