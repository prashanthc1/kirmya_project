# Kirmya Candidate Discovery & Search Manual for Recruiters

## 1. Candidate Search & Discovery Filters
- **Explicit Visibility Consent**: Only profiles where the candidate has explicitly toggled "Recruiter Visibility" or "Open to Opportunities" appear in discovery.
- **Search Criteria**: Filter by verified skills, experience tier, target role titles, location, and remote preferences.
- **Anti-Scraping Defenses**: Token-bucket rate limiting restricts bulk profile views, preventing unauthorized talent data scraping.
