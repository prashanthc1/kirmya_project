# Kirmya Recruiter Dashboard & Candidate Engagement User Guide

## 1. Navigating Recruiter Capabilities
- **Executive Recruiter Hub (`/recruiter`)**: Real-time overview of open positions, pending candidate reviews, upcoming interviews, and pipeline summaries.
- **Candidate Discovery & Outreach**: Search candidate profiles who have enabled recruiter visibility; reach out via context-aware direct messaging.
- **Talent Pool Organization**: Group high-potential candidates into customized talent pools for future vacancy outreach.
