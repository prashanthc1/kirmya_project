# Kirmya AI Memory Management & Context Retention Manual

## 1. Transparent Career Context Memory
- **Explicit Memory Capture**: Stores user-approved preferences (desired roles, target industries, preferred compensation range).
- **User Memory Controls**: Full visibility to inspect, edit, or wipe individual memory records or clear the entire memory cache.
- **Strict Data Siloing**: AI memory is strictly scoped to the authenticated user and never leaks across user accounts.
