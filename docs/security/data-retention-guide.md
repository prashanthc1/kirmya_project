# Kirmya Data Retention Schedules & Automated Purging Manual

## 1. Retention Windows & Automated Garbage Collection
- **Audit & Security Logs**: Retained for 90 days before automated background purging.
- **Job Applications**: Preserved for 3 years post-closure to comply with recruitment dispute standards.
- **Deactivated Accounts**: Soft-deleted accounts purged permanently after a 30-day grace restoration window.
