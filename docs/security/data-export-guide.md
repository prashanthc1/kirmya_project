# Kirmya Data Portability & Subject Access Request Export Manual

## 1. User Data Export Pipeline
- **Portability Package**: Compiles complete JSON archives of profile records, application histories, and saved assets.
- **Pre-Signed Download Links**: Export archives are delivered via expiring, single-use signed download links.
- **Export Rate Limiting**: Max 1 export request per 24 hours per user account to prevent infrastructure overload.
