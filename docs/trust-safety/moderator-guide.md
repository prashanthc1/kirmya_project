# Kirmya Trust & Safety Moderator Handbook & Triage Protocols

## 1. Case Handling Standard Operating Procedures
- **Triage Protocol**: Review incoming reports in the Admin Moderation Queue (`/admin/moderation`).
- **Evidence Verification**: Corroborate message headers, job descriptions, and user history before issuing penalties.
- **Fairness & Neutrality**: Never issue permanent bans without verifying against verified fraud patterns or severe hate speech criteria.
- **Audit Logging**: Every action requires a standardized rationale code and internal note.
