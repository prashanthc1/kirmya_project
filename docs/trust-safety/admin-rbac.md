# Kirmya Admin Role-Based Access Control (RBAC) Architecture

## 1. Administrative Roles & Scope

| Role | Scope & Permissions |
| :--- | :--- |
| **Super Admin** | Full system configuration, maintenance mode, role assignments |
| **Trust & Safety Admin** | Full moderation authority, permanent suspensions, appeals review |
| **Content Moderator** | Queue triage, content removal, warnings, temporary feature restrictions |
| **Support Admin** | User assistance, 15-minute expiring support impersonation sessions |
| **Analytics Admin** | Platform telemetry, aggregate safety metrics, executive reports |
