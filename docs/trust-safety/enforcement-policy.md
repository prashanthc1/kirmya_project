# Kirmya Platform Enforcement Policies & Violation Matrix

## 1. Violation Matrix & Penalty Escalation
| Severity Level | Examples | Standard Enforcement Action |
| :--- | :--- | :--- |
| **Low** | Off-topic self-promotion, mild etiquette breaches | In-app Policy Warning |
| **Medium** | Unsolicited bulk connection requests, repetitive spam | 7-day Feature Restriction (Messaging disabled) |
| **High** | Harassment, impersonation, discriminatory postings | 14-day Account Suspension |
| **Critical** | Advance-fee job fraud, credential phishing, malware links | Permanent Account Ban & IP/Device Flag |
