# Kirmya Learning & Skill Development User Guide

## 1. Navigating Learning Capabilities
- **Learning Hub (`/learning`)**: Access active learning paths, bookmark useful technical resources, track quiz assessments, and view certificates.
- **Career Roadmaps**: Visualize progression milestones from current role to target aspirational jobs.
- **Skill Endorsements**: Earn peer endorsements and validate competencies through practical assessments.
