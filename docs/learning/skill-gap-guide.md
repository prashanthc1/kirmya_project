# Kirmya Skill Gap Analysis & Job Readiness Diagnostic Manual

## 1. Skill Gap Diagnostic Engine
- **Target Role Mapping**: Evaluates candidate verified skills against live market job specifications and domain expectations.
- **Actionable Insights**: Highlights strong matching skills, identifies missing critical skills, and suggests targeted learning paths.
- **Privacy Assurance**: Diagnostic outcomes remain strictly private to the job seeker and are never shared with recruiters.
