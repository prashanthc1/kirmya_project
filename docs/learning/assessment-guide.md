# Kirmya Skill Assessments & Quiz Engine Manual

## 1. Skill Assessment & Quiz Execution
- **Deterministic Scoring**: Multiple-choice and scenario quizzes scored deterministically on the backend.
- **Anti-Cheating Controls**: Randomized question ordering, timed attempt windows, and answer secrecy prevent test manipulation.
- **Verification Evidence**: Successful assessment completions serve as verified evidence for candidate skill badges.
