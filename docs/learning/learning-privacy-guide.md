# Kirmya Learning Privacy & Data Protection Manual

## 1. Privacy Protections & Personal Career Boundaries
- **Default Confidentiality**: Quiz attempts, learning velocity, unfinished modules, and skill diagnostics remain private to the user by default.
- **Selective Public Showcases**: Only user-approved credentials and completed certificates are rendered on public profiles.
- **Recruiter Isolation**: Employers cannot query candidate learning weaknesses or assessment struggle metrics.
